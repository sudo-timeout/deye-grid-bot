# deye-grid-bot

[![tests](https://github.com/sudo-timeout/deye-grid-bot/actions/workflows/test.yml/badge.svg)](https://github.com/sudo-timeout/deye-grid-bot/actions/workflows/test.yml)

Телеграм-бот для тих, у кого вдома інвертор Deye з батареєю. Пише, коли зникає і повертається світло,
і відповідає на питання, яке насправді хвилює під час відключення: **чи вистачить батареї до світла**.

## Навіщо я це зробив

Інвертор перемикається на батарею так тихо, що вдома цього навіть не помічаєш. Це добре, але є й інший бік:
ти не знаєш, що світла вже немає, поки випадково не відкриєш застосунок. А бойлер, пральна машина
і все інше в цей час спокійно з'їдають заряд.

Я довго шукав у Deye Cloud налаштування сповіщень, перебрав усе — і з'ясував, що пуш про зникнення мережі
там просто не приходить: ця подія лежить лише в центрі повідомлень усередині застосунку, а в API її немає зовсім.
Тож написав бота, який сам дивиться на напругу мережі на вході інвертора і пише в Telegram.

Потім захотілося більшого: щоб бот одразу казав, коли за графіком дадуть світло і чи дотягне батарея.
Так він і виріс.

## Як це виглядає

```
🔴 Світло зникло о 23:37. Працюємо від акумулятора.
🔋 Заряд: 100%
⚡ Навантаження: 0.29 кВт
⏳ Вистачить до 06:30 післязавтра (~30 год 50 хв), як зазвичай без світла (0.38 кВт)
📅 За графіком світло має з'явитися о 18:00 (через 3 год 0 хв).
✅ Батареї має вистачити, запас ~27 год 50 хв.
```

```
🟢 Світло повернулося о 18:12 (226 В).
Світла не було 2 год 35 хв.
🔋 Заряд: 100% → 91%
⚡ Використано з батареї ≈ 1.4 кВт·год
📉 Середній розряд за відключення: 0.36 кВт
📅 Наступне відключення за графіком о 20:00.
```

## Що він вміє

Головне — пише, коли світло зникло і коли повернулося, скільки його не було і скільки взято з батареї.

Прогноз «на скільки вистачить» рахується чесно. Без світла вдома зазвичай економлять, тому бот запам'ятовує,
як батарея розряджається саме під час відключень, і рахує за цим, а не за піковим навантаженням.
Поруч показує й варіант «якщо споживати як зараз».

Якщо підключити графіки відключень (див. нижче), бот каже, коли за графіком дадуть світло і чи вистачить заряду,
попереджає за 2–3 години, якщо на наступне відключення заряду не вистачить, нагадує за 30 хвилин,
надсилає графік на завтра, щойно його опублікують, і чесно пише, коли діють аварійні відключення
і графік нічого не означає. У підсумку дня видно, скільки мало бути без світла за графіком і скільки було насправді.

Ще дрібниці, які виявилися корисними: попередження про низький заряд, низьку чи високу напругу в мережі
та холодну батарею; повідомлення, якщо інвертор перестав надсилати дані (зазвичай це означає, що вдома зник інтернет);
оцінка реальної ємності батареї за відключеннями — цікаво для нової батареї.

У Telegram є команди `/status`, `/today`, `/schedule`, `/battery` і `/preview`. Отримувачів може бути кілька —
у мене, наприклад, повідомлення приходять і дружині.

## Як це працює

```
Інвертор → Wi-Fi логер → Deye Cloud ← Cloudflare Worker (раз на 2 хв) → Telegram
```

Бот живе в Cloudflare Workers на безкоштовному плані, тож не залежить ні від світла, ні від інтернету вдома
і не потребує жодного комп'ютера, який мав би постійно працювати. Кожен розгортає власну копію у своєму акаунті:
паролі від Deye і токен бота зберігаються як секрети вашого Cloudflare і більше нікуди не йдуть.

Відключенням бот вважає момент, коли напруга мережі на вході інвертора падає нижче 100 В або частота нижче 40 Гц
(без світла інвертор показує ~2 В і 0 Гц).

## Встановлення

Займає хвилин п'ятнадцять. Знадобиться:

- інвертор, підключений до застосунку Deye Cloud;
- безкоштовний акаунт [Cloudflare](https://dash.cloudflare.com/sign-up);
- Node.js 22.12 або новіший;
- роутер і обладнання провайдера, які живляться від інвертора — інакше під час відключення дані просто не дійдуть.

**1. Ключі Deye.** Зайдіть на [developer.deyecloud.com](https://developer.deyecloud.com) тим самим акаунтом,
що й у застосунку, відкрийте розділ **Application** і скопіюйте `App ID` та `App Secret` кнопками копіювання.
Червону кнопку «Update Secret» не натискайте — вона згенерує новий секрет.

**2. Бот у Telegram.** Напишіть [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте ім'я — отримаєте токен.
Відкрийте свого бота й натисніть **Start**. Свій chat id можна дізнатися в [@userinfobot](https://t.me/userinfobot).

**3. Розгортання.**

```bash
git clone https://github.com/sudo-timeout/deye-grid-bot && cd deye-grid-bot
bash setup.sh
```

Скрипт відкриє браузер для входу в Cloudflare, створить сховище, по черзі запитає ключі (введення приховане),
розгорне бота, підключить команди і надішле тестове повідомлення. Під час першого деплою wrangler попросить
придумати піддомен `*.workers.dev` — підійде будь-яке вільне ім'я латиницею.

Хвилини за дві прийде «🟢 Моніторинг запущено». Після цього напишіть боту `/status`.

<details>
<summary>Вручну, без setup.sh</summary>

```bash
npx wrangler login
npx wrangler kv namespace create STATE        # отриманий id — у wrangler.toml
npx wrangler deploy
for s in DEYE_APP_ID DEYE_APP_SECRET DEYE_EMAIL DEYE_PASSWORD TELEGRAM_BOT_TOKEN TELEGRAM_CHAT_IDS ADMIN_KEY; do

done
curl "https://deye-grid-bot.<піддомен>.workers.dev/setup?key=<ADMIN_KEY>"   # команди в Telegram
```

`ADMIN_KEY` — будь-який довгий випадковий рядок, наприклад `openssl rand -hex 16`.

## Графіки відключень

Це опційно. Графіки бот бере з [Alerts Energy](https://alerts.energy) — сервісу, який збирає графіки всіх обленерго
в одному місці. Їхній API доступний за підпискою (близько $2 на місяць). Без неї бот працює так само, просто без графіків.

1. Оформіть підписку на alerts.energy і скопіюйте API-ключ у кабінеті.
2. `npx wrangler secret put ALERTS_ENERGY_KEY`
3. У `wrangler.toml` вкажіть `SCHEDULE_AREA` — так, як область записана в адресі на alerts.energy
   (наприклад `kyivska-oblast`), і `SCHEDULE_QUEUE` — свою чергу. Потім `npx wrangler deploy`.
4. Відкрийте `https://<ваш-воркер>.workers.dev/schedule?key=<ADMIN_KEY>`. У полі `operators` будуть оператори області —
   впишіть свого в `SCHEDULE_SUPPLIER` і ще раз `npx wrangler deploy`. Це важливо: в області їх буває кілька
   (наприклад, обленерго й Укрзалізниця), і в кожного свій графік для тієї самої черги.
5. Напишіть боту `/schedule`.

Пам'ятайте, що графік показує *можливі* відключення: світло нерідко дають раніше, і бот так і пише —
«за графіком», а не «точно».

## Щоб бот не замовк непомітно

Якщо раптом зламається токен Deye, закінчиться ліміт API чи щось трапиться в Cloudflare, бот просто перестане писати —
і ви подумаєте, що світло є. Від цього рятує безкоштовний [healthchecks.io](https://healthchecks.io):
створіть там перевірку (Period 5 хв, Grace 10 хв), підключіть сповіщення на пошту чи в Telegram
і виконайте `npx wrangler secret put HEALTHCHECK_URL` з Ping URL. Бот відмічається після кожної перевірки,
а якщо замовкне — вам напише сам сервіс.

## Налаштування

У `wrangler.toml`, розділ `[vars]`; після змін — `npx wrangler deploy`.

| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `DEYE_DEVICE_SN` | порожньо | серійник інвертора; якщо порожньо — береться перший інвертор в акаунті |
| `BATTERY_KWH` | `0` | ємність батареї в кВт·год; `0` — взяти з інвертора (А·год × 51.2 В) |
| `MIN_SOC` | `20` | до якого заряду рахувати «на скільки вистачить»; найкраще — як «Вимкнення батареї» в інверторі |
| `SOC_LOW` | `30` | коли попереджати про низький заряд, % |
| `SUMMARY_HOUR` | `22` | о котрій надсилати підсумок дня (за Києвом); `-1` — не надсилати |
| `SCHEDULE_AREA`, `SCHEDULE_SUPPLIER`, `SCHEDULE_QUEUE` | порожньо | графіки відключень, див. вище |
| `DEYE_BASE_URL` | EMEA | змініть, якщо ваш акаунт Deye не в європейському дата-центрі |

Секрети: `DEYE_APP_ID`, `DEYE_APP_SECRET`, `DEYE_EMAIL`, `DEYE_PASSWORD`, `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHAT_IDS` (кілька — через кому), `ADMIN_KEY`, за бажанням `ALERTS_ENERGY_KEY` і `HEALTHCHECK_URL`.
Змінити будь-який: `npx wrangler secret put ІМ'Я`.

Службові адреси (усі з `?key=<ADMIN_KEY>`, ключ після setup.sh лежить у файлі `.admin_key`):
`/status` — прогнати перевірку зараз, `/debug` — сирі дані інвертора, `/test` — тестове повідомлення,
`/setup` — підключити команди Telegram, `/schedule` — що повертає Alerts Energy. Логи: `npx wrangler tail`.

## Чесно про обмеження

Повідомлення приходить через 1–4 хвилини після відключення: логер Deye вивантажує дані в хмару приблизно раз на дві хвилини.
Пришвидшити це може лише підтримка Deye. Відповідно, дуже короткі «моргання» мережі бот може не помітити.

Перевіряв я на однофазному Deye LV Hybrid. Якщо у вашої моделі поля називаються інакше (видно в `/debug`),
поправте регулярні вирази у функції `metrics()` у `src/index.js` — або напишіть мені, розберемося.

Ліміти Deye OpenAPI — близько 60 запитів на хвилину і 100 тисяч на місяць; бот використовує приблизно 22 тисячі.

**English.** A Telegram bot for Deye hybrid inverters that tells you when grid power goes out and comes back —
something the Deye Cloud app doesn't do — and whether your battery will last until power is back.
It learns how fast your battery drains during outages, can use Ukrainian outage schedules (via Alerts Energy),
and warns you in advance if the charge won't be enough. Runs for free on Cloudflare Workers; every user deploys
their own copy with `bash setup.sh`, so credentials never leave their own Cloudflare account.
